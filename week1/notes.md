CS 50 - Week 1: C
Projects Completed: hello, mario-less, mario-more, cash

Overview

These introductory C programs strengthened my understanding of low-level programming fundamentals, including data types, control flow, input validation, and algorithm design. Each project progressively increased in logical complexity, reinforcing structured problem-solving and debugging skills.

Key Challenges

-Control Flow Precision:
Implementing nested for loops in mario-less and mario-more required careful planning to ensure correct alignment and symmetry. Small logic miscalculations directly affected output formatting.

-Input Validation:
Ensuring robust input handling using get_int() with conditional loops improved my understanding of programming and user input constraints.

-Algorithmic Thinking (Cash – Greedy Algorithm):
The cash problem introduced algorithm efficiency considerations. Implementing the greedy approach highlighted how ordering operations (quarters → dimes → nickels → pennies) directly impacts correctness and optimisation.

-Debugging & Compilation Errors:
Early syntax errors (missing semicolons, incorrect variable scope, bracket mismatches) improved my familiarity with compiler feedback and systematic debugging.

Achievements

-Developed a stronger understanding of how high-level logic translates into structured C code.

-Improved confidence working with loops, arithmetic operators, and conditionals.

-Practised breaking down problems into smaller, testable components.

-Began thinking more analytically about efficiency and program structure rather than just output correctness.

Reflection

These projects marked the transition from simply writing code to intentionally designing logic. I’ve improved in tracing program execution step-by-step and debugging independently. The experience reinforced that programming in C demands precision and clear thinking — a strong foundation for further study in systems, security, and more advanced development work.
